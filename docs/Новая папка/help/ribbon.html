Лента команд Velum

Группа Velum на ленте SOLIDWORKS. Доступность команд зависит от типа активного документа и уровня доступа (admin / user в настройках).

Раздел: ribbon

Адаптер настроен для SOLIDWORKS 2019; на других версиях полноценный функционал не гарантируется.
Старт / Стоп относятся только к помощнику на панели «Агент». Реестры, материалы, свойства и пакетный DXF/PDF работают без запуска помощника — но пакетные команды и настройки доступны только администратору проекта.

Меню Инструменты → Velum: те же команды, что на ленте (Старт, Стоп, Настройки, пакеты, реестры, справка). Серые пункты недоступны в текущем контексте (например, DXF/PDF пакет без открытой сборки).

Уровень доступа

В файле %ProgramData%\VELUM\Settings\Settings.xml параметр ProductRegistryAccessLevel принимает значения admin (по умолчанию) или user.

  • admin — полный набор команд ленты (с учётом контекста сборка/чертёж).
  • user — доступны Реестр документов (в основном чтение), Тех. требования, Реестр изделия и Справка. Старт помощника, настройки, пакетные материалы/свойства/DXF/PDF — недоступны.

Команды

КомандаНазначениеКонтекст документаДоступ
Старт Запустить цикл помощника (панель «Агент» начинает обновляться и принимать указания). Если ядро ещё не инициализировано — выполняет инициализацию. Любой Только admin; кнопка активна, когда цикл не запущен и помощник не «мёртв»
Стоп Остановить цикл помощника. Любой Только когда помощник готов и цикл запущен
Настройки Открыть настройки проекта (пути данных и параметры помощника). Любой Только admin
DXF пакет Пакетная диагностика и экспорт DXF по составу активной сборки (позиции с «Нужен dxf = Да»). Сборка Только admin + открыта сборка
PDF пакет Пакетная диагностика и экспорт PDF по составу активной сборки. Сборка Только admin + открыта сборка
Материалы пакет Пакетное присвоение материалов деталям по конфигурациям из выбранного каталога. Любой Только admin
Свойства пакет Пакетное обновление свойств деталей и сборок. Любой Только admin
Реестр документов Каталог файлов (ключ — полный путь) и виртуальные папки. Любой Всем (у user — без прав изменения)
Тех. требования Шаблоны и вставка технических требований на чертёж. Чертёж Всем
Реестр изделия Состав активной сборки, отчёты, хаб экспорта DXF/PDF. Сборка Всем
Справка Открыть справку Velum со стартовой страницы (оглавление). Любой Всем

Почему команда серая

  • Неверный тип документа: для реестра изделия и DXF/PDF пакета нужна сборка, для тех. требований — чертёж.
  • Уровень user: пакетные команды, настройки и Старт недоступны.
  • Старт/Стоп зависят от состояния цикла помощника (уже запущен, «мёртв», не инициализирован).

Дополнительно после загрузки надстройки появляется панель задач «Агент» — см. описание панели.
