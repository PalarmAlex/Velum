Справка Velum

Справка надстройки Velum для SOLIDWORKS. С ленты команд Velum — кнопка «Справка»; из диалогов — кнопка справки с иконкой рядом с действиями формы.

Целевая платформа: адаптер Velum настроен и проверяется для SOLIDWORKS 2019. На других версиях SOLIDWORKS полноценный функционал не гарантируется.
Файлы: %ProgramData%\VELUM\help (обычно C:\ProgramData\VELUM\help). Исходники в поставке/сборке — docs\help проекта; при сборке копируются в ProgramData. Часть команд ленты требует уровень admin и контекст сборки/чертежа — см. Ленту команд.

Быстрый старт

  1. Обзор — что умеет Velum и когда нужен помощник.
  2. Реестр изделия — типичная работа со сборкой (агент не обязателен).
  3. Лента команд — все команды и контекст (сборка / чертёж).
  4. Панель «Агент» — если пользуетесь помощником: зоны панели и «почему кнопка не сработала».
  5. ISIDA и МВАП — по желанию: адаптер Velum, ядро помощника и теория (со ссылками).
