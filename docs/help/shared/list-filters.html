Маски фильтров списков

Единый синтаксис фильтрации таблиц в реестрах, материалах, свойствах, ТТ и пикерах. В окнах рядом с полями фильтра есть кнопка ?.

Раздел: list-filters · путь: %ProgramData%\VELUM\help\shared\list-filters.html

Правила

  • Несколько столбцов объединяются через И (AND).
  • В одном поле несколько значений через | — через ИЛИ (OR).
  • Спецсимвол в начале строки действует на все токены поля.

Операторы

ОператорСмысл
(без символа) или *Вхождение (LIKE %текст%)
=Точное совпадение
!=Не равно (точное)
!Исключить вхождение (NOT LIKE)
> >= < <=Числовое сравнение

Примеры

Ф1|Ф2|Ф3          — содержит Ф1 или Ф2 или Ф3
=Ф1|Ф2            — равно Ф1 или Ф2
!=Ф1|Ф2|Ф3        — не равно ни одному из набора
!чертеж|эскиз     — не содержит «чертеж» и не содержит «эскиз»
*плита            — содержит «плита» (явный *)
>10               — число больше 10
>=1,5|2           — число ≥ 1,5 или ≥ 2
<100|50           — число < 100 или < 50
Числовые сравнения используют сырое значение ячейки. Остальные операторы — по тексту, как в списке.

Фильтр по выделенному

В списках с контекстным меню доступны пункты Фильтр по выделенному (=) и Исключить выделенное (!=). Берутся значения столбца, по которому открыто меню, у всех выделенных строк.

  • Если поле фильтра пустое — подставляется =значение или !=значение (несколько через |).
  • Если в поле уже та же маска — новые значения молча добавляются в конец через | без дубликатов (например !=23,007|23,020).
  • Если маска другая — диалог с тремя вариантами: Да — добавить выделенное и поставить новую маску всем токенам поля; Нет — заменить содержимое поля новым фильтром только по выделенному; Отмена — без изменений.

Применение

Фильтр применяется кнопкой Применить (или Enter в поле фильтра). Сброс очищает поля и показывает полный список. Кнопка ? рядом с фильтрами открывает эту страницу справки.

Где используется

Реестр изделия, реестр документов, материалы/свойства пакет, технические требования, выбор показателей и суффиксов DXF, списки отчётов и другие табличные формы Velum с единым помощником фильтров.
