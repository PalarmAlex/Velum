Поля выгрузки BOM

Настройка состава, порядка и заголовков столбцов CSV-файла обмена с 1С. Состав полей одинаково применяется к таблице в окне экспорта и к самому CSV-файлу.

Окно: «Поля выгрузки BOM в 1C» · раздел: bom-exchange-layout

Как открыть

В окне «Экспорт BOM в 1C» нажмите кнопку Поля….

Вкладка «Поля выгрузки»

Таблица со всеми доступными колонками выгрузки. Порядок строк сверху вниз — это порядок столбцов в CSV и в списке экспорта.

СтолбецНазначение
ВклВключать ли колонку в выгрузку. У обязательных системных полей (TypeDocs, ExternalId, Designation, Name, Quantity) отключить нельзя.
ПолеВнутреннее имя поля или свойства. Не редактируется: переименование свойства выполняется во вкладке «Отслеживаемые свойства».
ИсточникСистемное — служебное поле зеркала BOM; Свойство — отслеживаемое свойство компонента.
Заголовок в CSVТекст заголовка столбца. Для системных полей зафиксирован, для свойств — редактируется. Пустое значение заменяется именем поля.
ТочностьЗнаков после запятой для числовых значений свойства (0–15). Только для чтения: задаётся в окне «Отслеживаемые свойства BOM». У системных полей пусто.
ШиринаШирина колонки в окне экспорта, пикселей. Только для чтения.
Редактируются только флаг Вкл, Заголовок в CSV (у отслеживаемых свойств) и порядок колонок. Системные поля выделены серым фоном: их заголовок неизменяем, а поля TypeDocs, ExternalId, Designation, Name, Quantity нельзя ещё и выключить.

Кнопки справа от таблицы:

  • Вверх / Вниз — переместить выбранную колонку в порядке выгрузки;
  • Синхронизировать — добавить недостающие и убрать удалённые свойства из списка полей по текущим настройкам отслеживаемых свойств;
  • Сбросить… — вернуть состав, порядок и заголовки к значениям по умолчанию (сохранится только после OK).

Вкладка «Отслеживаемые свойства»

Показывает текущий список свойств, значения которых выгружаются, и их точность. Кнопка «Редактировать отслеживаемые свойства…» открывает окно «Отслеживаемые свойства BOM». После его закрытия список полей выгрузки обновляется автоматически: добавляются новые свойства и удаляются те, что были удалены в редакторе.

Сохранение

Нажмите OK — состав, порядок и заголовки колонок запишутся в %ProgramData%\VELUM\AssemblyRegistry\bomExchangeLayout.json. Отмена закрывает окно без изменений.

Если выключить все поля, экспорт вернёт сообщение «Не выбрано ни одного поля для выгрузки» и файл создан не будет.
