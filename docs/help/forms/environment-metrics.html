Метрики среды

Какие метрики работы в SOLIDWORKS и среде показывать на панели «Агент». Это справочная сводка для оператора: включать все не обязательно — для повседневной работы достаточно нескольких привычных пунктов или вовсе пустой сетки.

Окно: «Метрики среды» · раздел: environment-metrics

Как открыть

Панель «Агент» → кнопка … у сетки метрик.

Окно выбора: фильтр по имени, переключатели состояния Все / Вкл / Выкл, список с флажками, переключатели «Выбрать все» / «Сбросить все», внизу Применить, Закрыть и кнопка справки.

Зачем это нужно

Метрики помогают видеть «здоровье» сессии CAD и связанные артефакты (реестр, DXF/PDF), если вы пользуетесь помощником. Они не заменяют команды ленты и не обязательны для реестра или экспорта.

Элементы окна

ЭлементНазначение
Поле фильтра + Применить / Сброс / ? Отбор строк списка по названию (маски — как в других формах). «Сброс» очищает поле фильтра. «?» — справка по маскам.
Переключатели состояния Все / Вкл / Выкл Показать все метрики, только уже включённые на панели или только выключенные. Состояние учитывается при нажатии Применить (фильтр). Удобно быстро найти, что ещё не выведено в сетку.
Список с флажками Каждая строка — метрика. Галочка = показывать на панели «Агент» после применения.
Переключатели Выбрать все / Сбросить все Отметить или снять флажки у всех метрик списка. Действуют сразу при выборе переключателя, до «Применить».
Применить Сохранить набор отмеченных метрик на панели «Агент».
Закрыть Закрыть окно. Без «Применить» изменения флажков не сохраняются.
Кнопка справки (иконка) Этот раздел справки.

Примеры метрик

Конкретный набор зависит от профиля в %ProgramData%\VELUM. Среди типичных:

  • Материал в модели — назначен ли материал;
  • Несохранённый документ — есть ли несохранённые изменения;
  • PDF / DXF: наличие файла, устарел — состояние артефактов экспорта;
  • Габарит заготовки: ссылки — связанные проверки габарита;
  • Реестр: битые ссылки, нет чертежа — целостность реестра документов.

Включайте на панели только то, чем реально пользуетесь. Подробности по отдельной метрике (если доступны) открываются из сетки на панели — окно детали «кирпичика» метрики.
