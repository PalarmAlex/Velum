Экспорт BOM в 1С

Формирование CSV-файла обмена с 1С: состав сборок и отслеживаемые свойства компонентов (например, «Материал», «Масса»), изменившиеся с момента последнего обмена.

Окно: «Экспорт BOM в 1C» · раздел: bom-exchange

Как открыть

Через conditioned-рефлекс «Обмен BOM с 1С» (рецепт bom_exchange_show_dialog, действие среды ID 48). Окно открывается, когда срабатывает связанное с ним действие среды — например, при расхождениях BOM. Прямого пункта на ленте нет.

Как это работает

Velum автоматически при каждом сохранении детали или сборки запоминает состав и значения отслеживаемых свойств в локальном зеркале (%ProgramData%\VELUM\AssemblyRegistry\bomMirror.json). При изменении свойств или количества соответствующая позиция помечается как «расхождение». Файл обмена содержит только позиции с расхождениями и заполненным идентификатором связи с 1С.

Элементы окна

ЭлементЧто делает
Каталог обмена Сетевой или локальный каталог, куда записывается CSV-файл. Значение сохраняется в настройках проекта (кнопка Обзор выбирает каталог).
Таблица расхождений Список позиций с расхождениями. Столбцы: TypeDocs (Assembly/Part), ExternalId, Designation, Name, Quantity.
Настройки Открывает окно «Отслеживаемые свойства BOM» — список свойств, изменения которых отслеживаются. Настройки разделены по типу документа: сборки и детали.
Экспорт Формирует CSV-файл с расхождениями. После успешной записи расхождения сбрасываются — метрика «BOM» возвращается в норму до следующего изменения.
Закрыть Закрывает окно без экспорта.
Кнопка Экспорт активна, только если указан каталог обмена.

Формат CSV-файла

Кодировка UTF-8 с BOM, разделитель — точка с запятой. Имя файла: 1C_update_ГГГГ.ММ.ДД.ЧЧ.ММ.СС.csv.

Колонки:

  • TypeDocs — тип документа: Assembly (сборка) или Part (деталь);
  • ExternalId — идентификатор связи с 1С (свойство компонента в SOLIDWORKS, заполняется вручную);
  • Designation, Name — обозначение и наименование;
  • FilePath, Configuration — путь к файлу и конфигурация;
  • Quantity — количество вхождений;
  • далее — отслеживаемые свойства (настраиваются отдельно).
Позиции без заполненного свойства ExternalId в файл обмена не попадают.

Типовой порядок работы

  1. Заполните свойства ExternalId в компонентах и сохраните документы — Velum зеркалирует состав и свойства автоматически.
  2. Укажите каталог обмена и при необходимости настройте список свойств.
  3. Нажмите Экспорт и передайте файл в 1С.

Данные на диске

Зеркало состава и свойств — %ProgramData%\VELUM\AssemblyRegistry\bomMirror.json; список отслеживаемых свойств — bomTrackedProperties.json в том же каталоге. Каталог обмена хранится в настройках проекта.
