Отслеживаемые свойства BOM

Список пользовательских свойств SOLIDWORKS, значения которых зеркалируются в реестр при сохранении документа и выгружаются в 1С при обмене.

Окно: «Отслеживаемые свойства BOM» · раздел: bom-tracked-properties

Как открыть

Окно «Экспорт BOM в 1C» → кнопка Настройки.

Элементы окна

ЭлементЧто делает
Список Текущий список отслеживаемых свойств (по умолчанию: «Материал», «Масса»).
Поле ввода + Добавить Добавляет новое свойство в список. Также срабатывает по клавише Enter. Повторы не допускаются.
Удалить выбранное Удаляет выделенное свойство из списка (также двойной щелчок по строке).
OK / Отмена Сохранить список / закрыть без изменений.

Как это работает

При сохранении детали или сборки Velum читает значения перечисленных здесь свойств (сначала конфигурационные, затем свойства документа) и записывает их снимок вместе с хэшем состояния в зеркало BOM. Если значения или количество вхождений изменились с момента последнего обмена — позиция попадает в следующий CSV-файл.

При изменении списка свойств новые свойства появятся в зеркале после очередного сохранения соответствующих документов. Значение «?» считается пустым.

Данные на диске

Список хранится в %ProgramData%\VELUM\AssemblyRegistry\bomTrackedProperties.json.
