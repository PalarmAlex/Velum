Отслеживаемые свойства BOM

Список пользовательских свойств SOLIDWORKS, значения которых зеркалируются в реестр при сохранении документа и выгружаются в 1С при обмене.

Окно: «Отслеживаемые свойства BOM» · раздел: bom-tracked-properties

Как открыть

Окно «Экспорт BOM в 1C» → кнопка Настройки.

Элементы окна

ЭлементЧто делает
Вкладки Окно разделено на вкладки: Сборки и Детали. Для каждого типа документа свой список отслеживаемых свойств.
Таблица свойств Содержит два столбца: Свойство (именование пользовательского свойства SOLIDWORKS) и Точность (количество знаков после запятой для числовых значений при округлении).
Добавить строку Добавляет новое свойство в список. Введите имя свойства и, при необходимости, точность. Также срабатывает по клавише Enter. Повторы не допускаются.
Удалить Удаляет выделенное свойство из списка (также клавиша Delete или правый клик → «Удалить»).
OK / Отмена Сохранить список / закрыть без изменений.

Как это работает

При сохранении детали или сборки Velum читает значения перечисленных здесь свойств (сначала конфигурационные, затем свойства документа) и записывает их снимок вместе с хэшем состояния в зеркало BOM. Если значения или количество вхождений изменились с момента последнего обмена — позиция попадает в следующий CSV-файл.

При изменении списка свойств новые свойства появятся в зеркале после очередного сохранения соответствующих документов. Значение «?» считается пустым.

Точность числовых значений

Для числовых свойств (например, «Масса.кг.») можно задать точность — количество знаков после запятой, до которых значение будет округляться перед выгрузкой в CSV. Это полезно, чтобы избежать расхождений из-за плавающей точки.

ЗначениеЭффект
0Число округляется до целого
1Один знак после запятой
3Три знака после запятой (по умолчанию для «Масса.кг.»)
и т.д.Указанное количество знаков
Если свойство не числовое (например, «Материал»), точность игнорируется.

Данные на диске

Список хранится в %ProgramData%\VELUM\AssemblyRegistry\bomTrackedProperties.json.
