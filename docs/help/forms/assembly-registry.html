Реестр изделия

Состав активной сборки: дерево каталогов (разделов), таблица конфигураций по шаблону столбцов, отчёты (включая «Состав сборки»), хаб экспорта DXF/PDF и диагностика путей. Агент не обязателен.

Окно: «Реестр изделия» · раздел: assembly-registry

Как открыть

Лента Velum → Реестр изделия. Активный документ должен быть сборкой. Доступно и администратору, и пользователю.

Основные области

  • Состав изделия — дерево каталогов (разделов). Поиск по полю «Имя:», переходы по результатам кнопками ▲ / ▼ / × (предыдущий / следующий / сброс). Кнопка Стоп: в покое перечитывает состав из SOLIDWORKS (сбрасывает кэш), во время загрузки — прерывает операцию.
  • Шаблон столбцов — выпадающий список Шаблон:, кнопки Экспорт / Импорт (сохранение/загрузка файла шаблонов), Отчёт (сформировать HTML по текущему виду), Отчёты (значок списка — открыть ранее сохранённые, отчёты) и значок шестерёнки (настройки столбцов).
  • Хаб экспорта — кнопки Экспорт DXF / Экспорт PDF по позициям текущего списка и поле Кол-во изделия: (целое ≥ 1): множитель количества, используется в формулах и итогах столбцов и передаётся в пакетный DXF/PDF.
  • Строка кнопок — кнопки Применить, Сброс, ? (маски фильтров, см. справку), флажок Все компоненты и кнопка Состав сборки (открывает одноимённый отчёт в браузере).
  • Фильтры — поля над списком, активируются кнопкой Применить.
  • Таблица — строки конфигураций/компонентов; внизу при необходимости итоги по столбцам (Sum/Min/Max/Avg). Двойной щелчок по строке — открыть документ позиции.

Реестр изделия: слева состав (каталоги/позиции) с поиском и кнопкой Стоп; справа — шаблон столбцов со значками отчётов и настроек, хаб Экспорт DXF / Экспорт PDF с полем Кол-во изделия, фильтры, строка кнопок (Применить, Сброс, ?, Все компоненты, Состав сборки) и таблица строк. Ошибка в формуле ячейки может отображаться как «#ошибка…».

Строка кнопок

ЭлементЧто делает
Применить Активирует текущие значения полей фильтров и обновляет таблицу.
Сброс Сбрасывает все поля фильтров и обновляет таблицу.
? Справочная информация о масках фильтров (справка).
Все компоненты Флажок для отчёта «Состав сборки»: показать все компоненты сборки; иначе — только те, что попали в текущий список.
Состав сборки Открывает в браузере отчёт «Состав сборки» — дерево компонентов с обозначениями, наименованиями и количеством (см. отчёты).

Типовой порядок работы

  1. Откройте сборку в SOLIDWORKS и вызовите реестр.
  2. Выберите или настройте шаблон столбцов.
  3. Настройте фильтры и нажмите Применить.
  4. Сформируйте отчёт «Состав сборки» или сохраните HTML-отчёт кнопкой Отчёт.
  5. При необходимости выполните экспорт DXF/PDF.

Контекстные меню

Дерево каталогов (изменения — для администратора): Добавить каталог, Переименовать, Удалить.

Список:

  • Открыть — открыть документ позиции в SOLIDWORKS.
  • Печать чертежей — выбрать и отправить на печать связанные чертежи выделенных позиций.
  • Фильтр по выделенному — подставить значения выделенных ячеек одного столбца в поле фильтра (=); при той же маске — дописать через |, при другой — диалог: добавить с новой маской / заменить поле / отмена.
  • Исключить выделенное — то же с маской !=.
  • Выделить все.
  • Изменить каталог / Сменить материал — для администратора: назначить раздел или материал выделенным строкам.

Данные на диске

Шаблоны столбцов и служебные данные реестра изделия — в %ProgramData%\VELUM\AssemblyRegistry. Последний выбранный шаблон запоминается в настройках. HTML-отчёты — в каталоге отчётов из настроек проекта.

Справочник шаблонов

Открывается значком шестерёнки в строке шаблона столбцов (или Копировать в окне настроек).

  • Содержит список имён шаблонов. Для администратора: добавление, удаление, переименование.
  • Удаление — подтверждение с пояснением, что изменения вступят в силу при нажатии кнопки «Применить».
  • Фильтр — поле над списком для быстрой фильтрации по имени.
  • Двойной клик по строке — выбор шаблона и закрытие окна.
