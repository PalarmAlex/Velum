Геометрические штамбы (ModelGeometryStamp / PdfModelStampAtExport)

Два поля реестра, которые хранят штамб геометрии модели в единой базе. По ним определяется устаревание PDF и чертежа при изменении геометрии детали.

Раздел: geometry-stamps

Зачем нужны

При изменении геометрии детали (перемещение линий, изменение размеров, добавление/удаление элементов) соответствующие документы (PDF, чертёж) становятся устаревшими. Штамбы позволяют системе автоматически обнаруживать такие изменения через реестр — без открытия документов.

Важно: штамбы хранятся только в реестре, а не в свойствах документов. Это решает проблему «бесконечного» сигнала: при сохранении детали штамб обновляется из свойств (через ExportMetaSync), а при экспорте PDF или пересохранении чертежа — PdfModelStampAtExport обновляется из реестра. Никаких чужих свойств не трогаем.

Поля реестра

Поле реестраГде хранитсяНазначение
ModelGeometryStamp Запись детали (.sldprt / .sldasm) Текущий GetUpdateStamp() детали. Обновляется автоматически при открытии/сохранении детали через ExportMetaSync. Это единая база «сколько раз геометрия менялась».
PdfModelStampAtExport Запись чертежа (.slddrw) Значение ModelGeometryStamp связанной детали на момент экспорта PDF (или пересохранения чертежа). Если ModelGeometryStamp детали больше — PDF устарел.

Логика работы

  1. Открытие/сохранение детали. ExportMetaSync читает GetUpdateStamp() и записывает в реестр: ModelGeometryStamp = GetUpdateStamp().
  2. Экспорт PDF. После успешного экспорта PDF берётся текущее ModelGeometryStamp детали из реестра и записывается в PdfModelStampAtExport чертежа.
  3. Пересохранение чертежа. При Ctrl+S на чертеже обновляется PdfModelStampAtExport чертежа тем же значением, что ModelGeometryStamp детали (чертёж «принял» изменения геометрии).
  4. Проверка устаревания. Если ModelGeometryStamp (деталь) > PdfModelStampAtExport (чертёж) — PDF устарел.
Переходный период: если PdfModelStampAtExport ещё не записан (старые записи), система автоматически сравнивает ModelGeometryStamp детали с PdfGeometryUpdateStamp чертежа. Это обеспечивает корректную работу и для старых, и для новых записей.
Важно: штамбы не записываются в свойства документов. Они живут только в реестре. При открытии детали ExportMetaSync синхронизирует ModelGeometryStamp из свойств, а при экспорте PDF / пересохранении чертежа — PdfModelStampAtExport обновляется в реестре.

Механизмы обнаружения устаревания PDF

Система использует три независимых механизма:

1. Реестр (приоритетный)

При открытии чертежа система сравнивает ModelGeometryStamp связанной детали с PdfModelStampAtExport чертежа. Если геометрия модели изменилась — PdfGeometryPendingStamp на чертеже обновляется → PDF помечается как устаревший.

При глобальном сканировании (когда документы закрыты) PdfFleetScanner проверяет то же условие: ModelGeometryStamp > PdfModelStampAtExport. Также сохраняется существующая проверка по PdfGeometryPendingStamp чертежа (для ручных правок на чертеже).

2. GetUpdateStamp чертежа (fallback)

Если чертёж не заведён в реестре — система использует fallback: сравнивает текущий GetUpdateStamp() чертежа с PdfGeometryUpdateStamp. Если чертёж перегенерировался (источник изменился) — GetUpdateStamp() растёт.

Это покрывает стадию проектирования, когда документы ещё не завезены в реестр.

3. Геометрия листа чертежа (пульс)

На каждом пульсе система проверяет токены эскизов и аннотаций на листе чертежа. Если пользователь вручную дорисовал что-то на чертеже — это также считается изменением и помечает PDF как устаревший.

Пример

Сценарий: изменение геометрии детали и автоматическое обнаружение устаревания.

  1. Деталь Кронштейн.sldprt и чертёж завезены в реестр.
  2. Штамбы: ModelGeometryStamp = 10, PdfModelStampAtExport = 10 (PDF экспортирован).
  3. Пользователь открывает деталь, меняет размер отверстия, сохраняет. ExportMetaSync обновляет: ModelGeometryStamp = 12.
  4. Пользователь открывает чертёж. Система видит: 12 > 10 → PDF устарел.
  5. Глобальное сканирование: 12 > 10 → PDF помечается как «Устарел».
  6. Пользователь экспортирует новый PDF → PdfModelStampAtExport = 12.
  7. Проблема устранена.
