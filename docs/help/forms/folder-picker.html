Выбор каталога

Общий диалог «Выбор каталога» открывается по кнопке Обзор… в настройках проекта, реестрах, карточке изделия, экспорте и других формах с полем пути.

Раздел: folder-picker · окно: «Выбор каталога» · путь: %ProgramData%\VELUM\help\forms\folder-picker.html

Состав окна

ЭлементНазначение
Дерево каталоговРабочий стол и готовые диски. Вложенные каталоги подгружаются при раскрытии узла, поэтому дерево не «вешает» интерфейс на больших сетевых каталогах.
Поле путиПуть выбранного каталога. Можно ввести или вставить вручную — кнопка Выбрать станет доступной, если каталог существует.
Создать каталогСоздаёт новый каталог внутри выбранного и сразу выделяет его в дереве.
Выбрать / ОтменаПринять выбранный каталог / закрыть без записи. Двойной щелчок по узлу равен Выбрать.

Скрытые и системные каталоги

Диалог показывает каталоги так же, как Проводник Windows, — правила берутся из текущей настройки вида папок этого пользователя:

Атрибут каталогаКогда виден в дереве
ОбычныйВсегда.
Скрытый (например AppData, ProgramData)Если включён «Показывать скрытые файлы, папки и диски».
Системный (например $RECYCLE.BIN)Если снят флажок «Скрывать защищённые системные файлы».

Как включить показ

  1. Проводник → Вид → Показать → Скрытые элементы (Windows 10/11) — включает показ скрытых каталогов.
  2. Для системных каталогов: Вид → Параметры (в Windows 11 — … → Параметры) → вкладка Вид → снять «Скрывать защищённые системные файлы (рекомендуется)».
Настройки читаются из реестра (HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced, значения Hidden и ShowSuperHidden) при каждом открытии диалога. Если флажки уже были включены, дерево покажет эти каталоги сразу — перезапуск SOLIDWORKS не нужен.
Менять вид папок в Windows необязательно: нужный каталог можно просто ввести или вставить в поле пути — кнопка Выбрать работает и для каталогов, скрытых в дереве.

Начальный каталог

Диалог открывается на каталоге из поля формы. Если такого каталога нет (путь с другой машины, сетевой ресурс недоступен, каталог удалён), выделяется ближайший существующий родитель. Путь из поля доступен для Выбрать и когда это сетевой путь вне дерева дисков, и когда каталог скрыт при текущих настройках Проводника.
