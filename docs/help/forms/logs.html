Логи агента

Просмотр сохранённых логов работы агента ISIDA: системного журнала, журнала стилей поведения, журнала параметров гомеостаза и событийного лога (токены сокращённого лога движка). Данные читаются из CSV-файлов и выводятся HTML-отчётом.

Раздел: logs · заголовок: «Логи агента»

Как открыть

На панели «Агент» над областью «Ответ агента» справа есть кнопка Логи. Она открывает окно с четырьмя вкладками.

Окно «Логи агента»: вкладки Логи системы, Логи стилей, Логи параметров, Событийные логи, список сессий с галочками и кнопки Выделить все, Снять все, Обновить, Очистить, Каталог, Просмотр, Закрыть.

Работа с сессиями

Над вкладками есть поле фильтра: набранный текст отбирает сессии активной вкладки по вхождению в подпись (дата/время/число записей). Кнопка × справа очищает фильтр. Фильтр применяется к каждой вкладке независимо; уже проставленные отметки сохраняются.

На каждой вкладке — список сессий (непрерывных отрезков лога). Сессия подписана датой, временем начала и окончания и числом записей, например 03.10.2026 14:05–14:37 (1920).

  • Отметьте одну или несколько сессий галочками (двойной щелчок по строке тоже переключает отметку).
  • Выделить все / Снять все — массовые операции над видимыми (отфильтрованными) сессиями активной вкладки.
  • Обновить — перечитать список сессий из файлов логов.
  • Каталог — открыть папку логов %ProgramData%\VELUM\Logs.
  • Просмотр — сформировать HTML-отчёт по выделенным сессиям.
  • Очистить — удалить выделенные сессии активной вкладки и связанные с ними отчёты (см. ниже).

Очистка записей

Кнопка Очистить удаляет выделенные (отмеченные галочками) сессии активной вкладки. Для каждой сессии:

  • из соответствующего файла лога удаляются её строки — остальные сессии файла сохраняются;
  • удаляется связанный HTML-отчёт в подпапке Reports, если он есть.

Отчёт считается связанным с сессией, если его имя совпадает с именем сессии в списке: {префикс вкладки}_{yyyyMMdd_HHmmss}.html, где штамп — время начала сессии. Префикс различает вкладки (Логи_системы, Логи_стилей, Логи_параметров, Логи_событий), поэтому отчёты разных вкладок с одинаковым временем не путаются. Отчёты, сформированные ранее по времени нажатия кнопки «Просмотр» (до этого обновления), автоматически не находятся и остаются в папке Reports.

Действие необратимо: строки лога удаляются из файла без возможности восстановления. Перед удалением выводится подтверждение с числом сессий.

Отчёт

Отчёт сохраняется в подпапку Reports каталога логов под именем, привязанным к выделенным сессиям: {префикс вкладки}_{yyyyMMdd_HHmmss}.html (штамп — время начала самой ранней выделенной сессии). После сохранения предлагается открыть отчёт в браузере. Отчёт оформлен в обычном стиле; у каждой ячейки и заголовка есть всплывающая подсказка (атрибут title): наведите курсор на ячейку, чтобы увидеть расшифровку — например, названия стилей, действия рефлекса, фразы триггера, давление метрик среды.

Шапка таблиц фиксированная: при прокрутке длинного отчёта вниз строка заголовков столбцов остаётся прикреплённой к верху окна, поэтому подписи колонок не теряются даже в логах на тысячи пульсов. При печати отчёта шапка ведёт себя как обычно (повторяется браузером по необходимости).

В системном логе колонка Триггер показывает пусковой стимул «чей мотор в строке, тот триггер»: в строке запуска автоматизма — ID узла дерева автоматизмов, по которому сматчился автоматизм; в строках рефлексов — ID образа восприятия, предъявленного на пульсе (воздействие, фразы, команды, тон, настроение, цвет). Числовые ID узла дерева и образа восприятия принадлежат разным пространствам имён и не сопоставляются между собой.

Событийный лог

Вкладка Событийные логи показывает токены сокращённого лога движка — тот же поток, что панель «Агент» выводит в окне «Ответ агента». Токен отображается двумя строками: заголовок № пульса: NNN (при нескольких одинаковых токенах подряд — № пульса: NNN ×K) и сам текст. В отчёте токены идут в хронологическом порядке; если выделенные сессии пусты, выводится «Нет записей для отчёта.».

Файл вкладки — AgentLogs_Events.csv в каталоге логов (настраивается в параметрах проекта, по умолчанию %ProgramData%\VELUM\Logs). Формат: блок на сессию, строка-заголовок Time;Pulse;Repeat;Text, далее строки HH:mm:ss;пульс;повторы;текст. Текст экранируется, чтобы разделитель ; и переводы строк внутри текста не разрывали запись; при чтении экранирование снимается, и текст восстанавливается полностью.

Событийный лог пишет сам Velum — сессия дописывается в файл в момент остановки пульсации (когда пульс завершает сессию). Пока пульсация идёт, текущая сессия в файл ещё не записана и во вкладке не появится; нажмите Обновить после остановки.
Логи пишет симбионт ISIDA. Если вкладка пуста — соответствующий CSV-файл ещё не создан или не содержит завершённых сессий. Файлы: AgentLogs.csv, AgentLogs_Styles.csv, AgentLogs_Parameters.csv, AgentLogs_Events.csv.
