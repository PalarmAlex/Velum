# AGENTS.md — Правила проекта Velum

## Общие принципы

- **Простота прежде всего.** Старайтесь сделать задачу максимально простой. Не усложняйте там, где не нужно.
- **Факты важнее предположений.** Не галлюцинируйте. Проверяйте факты, прежде чем предоставлять информацию.
- **Действуйте, а не только описывайте.** При создании или изменении кода всегда используйте инструменты для реальных изменений в файлах.

## Компиляция

- Используйте MSBuild, встроенный в Visual Studio Professional 2022.
- Команда для компиляции проекта `Velum.csproj`:

```powershell
& "C:\Program Files\Microsoft Visual Studio\2022\Professional\MSBuild\Current\Bin\MSBuild.exe" D:\VELUM\Velum\Velum.csproj /t:Build /p:Configuration=Debug /v:q /nologo
```

- **Не используйте** `dotnet build` — проект не поддерживает .NET SDK для сборки.
- **Не используйте** команду `msbuild` без полного пути — она не в PATH.

## XML-комментарии

- **Обязательные XML-комментарии (`///`)** — для каждого публичного/внутреннего типа, метода, свойства, поля, события, интерфейса.
- **Ошибка CS1591 уже включена** в `.csproj` (`<WarningsAsErrors>1591</WarningsAsErrors>`). Компиляция без комментариев не проходит.
- Пишите XML-комментарии **сразу** при написании/изменении кода, не откладывайте.
- Используйте `<summary>`, `<param>`, `<returns>` согласно стандартам C#.
- Комментарии в коде — на **русском языке**, если уже не встретились комментарии на английском в этом файле.

## Справка и документация пользователей

### Где находится справка

Справка Velum находится в `docs\help\` (проект) и копируется в `C:\ProgramData\VELUM\help\` (дистрибутив). Файлы одинаковые — при обновлении одной копируйте в другую.

Формы описаны в `docs\help\forms\` — по одному HTML-файлу на окно/форму.

### Обязательное обновление справки

**После каждого изменения, которое:**

- **Меняет алгоритм адаптера** — логику индексации, синхронизации свойств, классификации файлов, фильтрации, проверки путей и т.д.
- **Меняет интерфейс формы** — добавляет/удаляет/переименовывает элементы управления, кнопки, поля, меню, контекстные меню, всплывающие подсказки.
- **Меняет поведение формы** — новый диалог, новый результат операции, новое сообщение об ошибке/успехе.

**Необходимо:**

1. **Найти** соответствующую страницу справки в `docs\help\forms\`.
2. **Обновить** описание на странице, чтобы оно отражало новые изменения — выдерживая стиль изложения и оформления.
3. **Скопировать** обновлённую страницу в `C:\ProgramData\VELUM\help\forms\`.
4. **Если страницы нет** — создайте её, если изменения действительно стоит показать пользователю (не всё подряд, а то, что пользователь должен знать).

### Стиль справки

- HTML-файлы используют `styles.css` — совместимо с IE/WebBrowser (без flex/grid).
- Структура: `<h1>` — название окна, `<h2>` — разделы, `<ul>`, `<ol>`, `<table>` для списков и таблиц.
- `.note` — блок-примечание (синий фон, синяя полоса слева).
- `.warn` — блок предупреждения (жёлтый фон, жёлтая полоса слева).
- `.figure` — изображение с подписью (`.caption`).
- `.seealso` — блок "См. также" в конце страницы.
- `.meta` — дополнительная информация (окно, раздел).
- Код — через `<code>`, блоки кода — через `<pre><code>`.
- Ссылки на другие страницы справки — относительные пути (`../shared/list-filters.html`, `assembly-registry.html`).
- Язык — **русский** (страницы справки на русском языке).

## Код и стилизация

- Следуйте стилю существующего кода в проекте.
- Минимальные изменения для достижения цели.
- Тестируйте, что вы собираетесь построить.
- Комментарии в коде — на **русском языке**, если уже не встретились комментарии на английском в этом файле.
- В ответах пользователю — **русский язык**.

## Исправление ошибок

- Сначала проверьте логи ошибок и неудачные тесты.
- Отсканируйте кодовую базу, чтобы найти корневую причину.
- Убедитесь, что все указанные пользователем тесты проходят после изменений.

## Инструменты

- При создании/изменении файлов используйте `create_new_file` / `edit_file`.
- Для поиска — `grep_search`, `file_glob_search`.
- Для запуска команд — `run_terminal_command`.
- Для чтения — `read_file`.
